Module stream 

Source
Expand description

Stream verification: the device’s load-bearing gate (§6.2).

Input is the reassembled ur:zafu-stream buffer = manifest_cbor || image_wrapper (manifest is frame[0], at byte offset 0). Validates the manifest signature + image signature against the pinned key, then the applicability gates (blacklist / board / class / anti-rollback), then decodes the trailing image wrapper and re-derives the full-image hash.

Constants§

MAX_MODULE_SIZE
v1 module-image size cap (bytes). The delivered OTA target is a small signed module image, not a whole-firmware replacement; the freeze spec’s open item suggests ~250 KB for v1 but the product frame is a few MB. We cap at 3 MiB so a QR scan stays ~1-2 minutes and a runaway/malformed stream can never claim a huge payload to stage.
STAGING_CHUNK
Default staging chunk size used for per-chunk hash verification.
