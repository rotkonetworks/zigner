What the camera may hand to a parser on this device.

The camera is the only untrusted input. The camera layer classifies each code, and a network’s content parser is reachable only when this device holds something it would be used with: no Penumbra key, no Penumbra parsing; no Zcash key or FROST wallet, no Zcash parsing. The answer is derived from the database every time it is asked, so there is no setting that can drift from what the device holds.

This gates content parsers only. The multi-frame transport decoder (qr_reader_phone: RaptorQ, legacy frames, banana-split shares) runs on byte-mode codes before classification and is not covered here.

Three kinds stay open on an empty device, because they are how a device stops being empty: recovery (banana split and backup import), creating a FROST wallet, and signed module updates.
