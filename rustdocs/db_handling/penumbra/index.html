Penumbra keys as Zigner stores them

Spend keys, viewing keys and addresses come from penumbra-sdk, the same derivation the FVK export and signing use: SpendKey::from_seed_phrase_bip44 at m/44'/6532'/account'. The receive address is index 0 of that key, which is the address Zafu shows after importing the exported FVK.

key_id is only a database identifier. Zigner 0.12.0 and older keyed Penumbra entries by a verification key derived from a blake2b hash of the seed, and existing installs keep those keys, so new entries use the same id. It is not a Penumbra key and must not be shown as one.
